# PyGame Hot Rope

Pygame project inspired by the fire jump-rope game from Mario Party

## Setup

### Create & Activate virtual environment

```bash
python3 -m venv venv
```

```bash
source venv/bin/activate
```

## Run Game

Note: you must be in project root, not within `/src`

```bash
python3 src/main.py
```
